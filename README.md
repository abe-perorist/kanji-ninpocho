# 📜 かんじ忍法帖

小学1年・3年の漢字の読み・書きを、遊びながら覚えるブラウザゲーム。GitHub Pages で公開する。

## あそびかた

- **しゅぎょう**：10問。読み問題（赤い漢字の読みを選ぶ）と、かき問題（ふりがなを見て□に入る漢字を選ぶ）がまざって出る。まだ集めていない漢字は読み問題から
- **まきものちょう**：正解した漢字が巻物になる。1回で銅、3回で銀、5回で金
- **かんじ あわせ**：漢字カードと読みカード（訓はひらがな、音はカタカナ）をそろえる神経衰弱。めくった回数の自己ベストが残る
- **きょうだい たいけつ**：1台の画面を2人で分けて、60秒で何問正解できるかを競う。それぞれ自分の学年の問題が出る。まちがえると1秒お休み。縦置きにすると向かい合わせになる

プレイヤーは2人。名前と学年（1年／3年）はホーム画面で変えられる。

## 開発

ビルドなしの素の JS（ES Modules）。

```sh
python3 -m http.server 8000   # http://localhost:8000
npm test                      # 漢字データと出題ロジックのテスト
```

- `js/kanji-data.js` … 漢字データ。1行 `漢字|訓|音|ことば=よ[み]...`
- `js/quiz.js` … 出題・ひっかけの選択肢・巻物のレベル
- `js/storage.js` … localStorage（キーは `kanjiNinpocho.` で始める。計算忍者と同じオリジンになるため）
- `js/app.js` … 画面

漢字データのテストでは、学年別漢字配当表と一致していること、例のことばにその学年までに習う漢字しか使っていないことを確認している。
